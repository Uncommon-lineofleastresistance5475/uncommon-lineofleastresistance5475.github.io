## 🆘 Troubleshooting

### ❓ Pop-up Doesn't Appear

- Make sure lexiglance is running (check the system tray icon)
- Try clicking on the word instead of hovering
- Ensure you're not using a secure application that blocks overlays (some password managers and banking apps do this)
- Restart lexiglance by right-clicking the tray icon and selecting "Restart"

### ❓ Wrong Definitions

- Check your current dictionary selection in the settings
- Make sure the correct language is selected
- Some specialized terms may not appear in general dictionaries—try adding a specialized dictionary

### ❓ Slow Performance

- Close unnecessary applications to free up memory
- Reduce the number of active dictionaries
- Update to the latest version of lexiglance
